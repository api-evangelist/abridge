# Abridge

> Abridge provides enterprise-grade generative AI for clinical conversations, turning
> patient-clinician interactions into contextually aware, clinically useful and billable
> AI-generated notes. Its Contextual Reasoning Engine powers ambient documentation embedded
> directly inside the Epic EHR ("Abridge Inside"), deployed across more than 100 U.S. health
> systems including Mayo Clinic, UPMC, Kaiser Permanente, Johns Hopkins and Duke Health.

IMPORTANT FOR AGENTS: Abridge publishes **no public developer API**. As of 2026-08-15 there is
no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server, A2A agent card, SDK or
developer portal on any Abridge-operated host. Do not attempt to construct API calls against
abridge.com — there is no documented base URL, no authentication scheme and no reference to
call. Integration runs through Epic's Partners and Pals program and through enterprise
agreements negotiated with Abridge directly.
